# Balance line

A 13-bar smoothed moving average, offset 8 bars *forward* into the future. Williams calls it a "strange attractor": it represents where price would sit if no new information were hitting the market, so divergence from the balance line signals that new information has arrived.[^practical-fractal-video] This is the second of his [five dimensions of market structure](/concepts/five-dimensions-of-market-structure.md).

Note: the talk describes only this single balance line. Williams' later, more widely known "Alligator" indicator (jaw/teeth/lips — three offset moving averages) is not described in this source; this page covers only what the talk itself presents, and should be revisited if a source describing the full Alligator indicator is ingested.
